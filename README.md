Reto UT5 CV - Enunciado:

Piensa que estás desarrollando la funcionalidad completa de CV del nuevo crm de Altair.


Desarrolla la API que dará acceso a base de datos a esta parte del crm.

Una buena práctica es que, en el primer acceso de un usuario a la funcionalidad CV, tenga la opción de realizar un pequeño tutorial de cómo funciona el registro de los diferentes elementos del crm.

Entidades recomendadas:
Tablas que actúan como catálogo: alumnos, experiencias, formaciones, aptitudes.
Tabla que actúa como tabla de hechos: cv; relaciona todas las demás.
